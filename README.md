# StockSense AI 📈

An AI-powered Indian stock market intelligence dashboard built with Python and Streamlit.

## 🔴 Live Demo
[Click here to open the app](https://stocksense-ai-hjbfpkwzrtpqgfd222d6gj.streamlit.app/)
## 🚀 Features
- Live NSE/BSE stock data via yFinance
- Interactive candlestick charts
- MA10 & MA20 moving average overlays
- Real-time news sentiment analysis powered by TextBlob
- Live headlines fetched from NewsAPI

## 🛠️ Tech Stack
- Python
- Streamlit
- yFinance
- Plotly
- TextBlob
- NewsAPI
- Requests
